# Workend brand assets

Original PNG artwork supplied by the project owner; files are copied without modification.

- `workend-wordmark.png`: Workend 1.png, full gold symbol and wordmark. Used by the shared brand component in both portals, header, footer, and authentication dialogs.
- `workend-mark.png`: workend2.png, standalone gold mark retained for brand use.
- `workend-icon.png`: workend3.png, browser favicon.
- `workend-touch-icon.png`: workend 4.png, touch icon.

All artwork has a transparent background. CSS frames the wordmark inside its transparent canvas margins. In dark mode, a clipped duplicate lightens only the lettering; the gold symbol uses the original pixels. The Employer caption remains separate text.
